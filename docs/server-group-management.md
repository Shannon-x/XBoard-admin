# 权限组管理

- 列表支持搜索组名、ID、关联套餐、节点名称，按基础组 / 包含组 / 可选购增值组筛选。
- 每组展示具体套餐及关联方式，节点数区分显示与隐藏；基础组用户数明确不包含额外授权。
- 点击节点数量或“查看明细”，可切换组、搜索节点、筛选显示状态，查看节点协议与倍率，跳转节点管理。
- 关联套餐页显示具体套餐、关联方式、用户展示名、月费及显示/销售设置。历史计价引用单独说明，不作为可购买权限。
- 套餐编辑中的增值组显示 ID、完整后台组名和节点预览。预览独立加载、只读，不丢弃尚未保存的表单；手机用卡片展示节点和套餐。

需要后端 `server/group/fetch?include_details=1` 支持。旧调用保持精简，旧后端缺少明细时显示提示，避免误报为空组。后台重命名不会自动覆盖套餐设置的用户展示名。

验证：生产构建和 i18n 检查；模拟接口浏览器验收覆盖精确 ID、不同组节点隔离、隐藏筛选、关联套餐、历史计价提示、失败重试、320/390px、未保存表单、节点跳转，以及查看过程无写请求。内置模式使用 Xboard-sh 的 `scripts/patch-admin.sh` 构建后验证。
